# Trisha — Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio structure and content
- `style.css` — complete responsive design
- `script.js` — smooth scrolling

## Before publishing

Replace these placeholder links in `index.html`:

- GitHub URL
- LinkedIn URL
- Email address
- `View Project` links with your actual repository/live-demo URLs

## Run locally

Open `index.html` in a browser.
